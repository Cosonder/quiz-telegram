## 精灵布局

每帧 128 × 160，人物图集为四列、五行。行从上至下为 `idle`、`happy`、`sad`（关心/安慰）、`sleep`、`tap`，列从左至右为四个动画帧。统一脚底位置，保留原始透明边缘。配饰是一行三列，使用相同帧尺寸及颈部/发侧位置；只叠加当前选中的一件，不影响数值。

使用内置 imagegen 工具参考现有设定生成，完整提示词记录在 `prompts.json`。`french-quiz/tools/pet/pack-assets.py` 仅注册帧位置、缩放、拼图和 WebP 编码，不重新绘制角色。人物编码 quality=82、alpha_quality=80，配饰为88/90。原始生成 PNG 保存在本次工作区的 `output/claude-pet-art/`，不作为网页依赖。

未解锁或关闭时不自动加载图集，用户主动预览才加载对应角色；仅加载当前角色，佩戴/试穿时才加载配饰。系统减少动画或用户关闭角色动画时，使用该状态第一帧；后台页面暂停动画。没有自动语音或外部生成请求。

发布构建的 PWA 预缓存排除整个 `skins/mascot/`；素材由相对目录按需读取，已请求的资源仍使用现有 Service Worker 页面缓存。发布时须携带 `skins/`，不使用私有仓库 raw 地址。

## 功能与记录

沿用100金币的游戏模式前置，800金币通过 `buy` 商品解锁三人，不改变旧游戏的300/800/1500解锁梯度。配饰150/300/500金币，永久共享、无收益加成。未拥有的试穿只在伙伴面板生效。

亲密度按真实题目历史最高记忆等级与首次答对词汇派生；每日UTC上限20，总上限1000，三个角色共享，重复点击/答题不重复奖励。解锁前学习记录有效，缺席和答错不扣亲密度。五阶段为0/30/100/300/600，仅增加互动台词。

`kind:pet` 配置按账号scope和最新at合并；所有权使用已有buy账本，位置属于设备。本功能只隔离新增pet配置；全站既有答案归属及不同商品跨设备同时消费仍沿用原有规则，不宣称服务器防作弊或事务防超支。

390px与1280px三语审阅、隔离QA记录、测试命令及边界见 [桌宠验收说明](../../../french-quiz/tools/pet/README.md)。只提交Claude的french-quiz分支，公开网站由Claude发布。
